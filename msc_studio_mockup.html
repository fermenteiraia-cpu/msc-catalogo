Para quem está revisando este mockup:
Este é apenas um mockup interativo — nenhum botão dispara ação real. O objetivo é validar fluxo, hierarquia das telas e organização da informação antes de codar o app. Navegue clicando nas abas no topo (1 a 7) ou nos botões "Anterior/Próxima" no rodapé.

Aspectos para avaliar: fluxo (a ordem das telas faz sentido?), completude (algo essencial está faltando?), simplicidade (alguma tela está poluída?), terminologia ("briefing", "marca do projeto", "preview" — funcionam para os usuários reais?). Na tela 7 (Editor), há dois modos clicáveis: peça avulsa e catálogo completo — vale conferir os dois.
